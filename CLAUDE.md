# Working rules

- A task is done only when `npm run verify` passes. Report the result, not just "done".
- If the same mistake happens twice, add a lint rule, test, or boundary instead of a new note here.
- Append one line per non-obvious decision to `decisions.tsv` (time, decision, reason, evidence, result).
- Design rules live in `tests/rules.test.ts`; lessons follow `docs/superpowers/specs/2026-11-18-system-design-learning-design.md`.
- Plan: `docs/superpowers/plans/2026-11-18-system-design-learning-platform.md`.
